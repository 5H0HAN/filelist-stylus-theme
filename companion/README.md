# Public search and translation helper

Open `index.html` in a browser. Enter a title or file name, choose one
provider, and submit. Search destinations are Google, Bing, IMDb, and TMDB.
Academic Torrents is linked separately as a public research-dataset index; the
helper does not send your query there.

The search query is sent to the selected provider only when you submit the
form. The translation area only copies text locally. Open Google Translate,
paste the text there, and submit it there if you choose. The helper does not
read Filelist pages, save your queries, or make background requests.
